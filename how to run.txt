1. Open PowerShell/Terminal in this folder.

2. Create a virtual environment with Python 3.12:
py -3.12 -m venv .venv

3. Allow script activation for this session:
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

4. Activate the virtual environment:
.\.venv\Scripts\Activate.ps1

5. Upgrade pip:
python -m pip install --upgrade pip

6. Install dependencies:
pip install -r requirements.txt

7. Run the app:
python .\head_mouse.py


If there are any errors in depencies go in requirements and read the instructions there

Notes:
- Use Python 3.12.x
- MediaPipe is pinned to 0.10.21 because this script uses the legacy `mp.solutions.face_mesh` API
- If mouse control or key detection acts weird, try running PowerShell as Administrator
- If the camera does not open, allow camera access in Windows Privacy settings
- Keys used by the script:
  - C = calibrate / lock eye spheres
  - S = screen calibration
  - X = add marker
  - F7 = toggle mouse control
  - Q = quit
